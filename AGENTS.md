## Release Workflow

Before preparing or publishing a release, read
[Release Workflow](agents/release-workflow.md).

- Normal development PRs target `develop`; releases merge directly into `master`.
- A request to publish a specified version authorizes the complete standard
  release workflow. Respect narrower instructions, including preparation without
  pushing. Updating this document does not authorize publication.
- Preserve the zero-allocation logging paths when making release fixes.
